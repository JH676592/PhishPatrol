# Phish Patrol

Phish Patrol is a game for teaching people how to detect scams and phishing attempts so they can be safer on the Internet. The player begins by making an account with a username, password, name, and difficulty level. After logging in, they can review the rules of the game, read about different types of scams and phishing attempts, and click Play. The player is presented with what looks like the familiar computer desktop. Scenarios are generated by Gemini and fed into a queue. When a scenario becomes available, a badge appears on one of the icons, email or SMS. The player clicks on the icon and is presented with the scenario. They must choose whether the scenario represents a scam or a legitimate message. They are then presented with feedback, outlining how the message is either a scam or legit. Choosing incorrectly drains the battery icon on the task bar. Choosing incorrectly too many times in a row causes the player to lose. They can then choose to play again. 

## Codebase

To implement the game, we chose SvelteKit to handle the main functionality, as well as Spring to implement the leaderboard and track player information. 

We used SvelteKit's component system to factor out the login modal, the desktop icons, info window, and the scenario window. We used SvelteKit's stores to keep handle bookkeeping, such as authentication and the scenario queue. The main interactive logic was kept in the SvelteKit routes.

## Setting up the codebase

To run the game locally, open a terminal in the phish-patrol/ and phish-patrol-frontend/ directories. These contain the Spring and SvelteKit codebases respectively. They must be ran concurrently. 

To run the Spring codebase, execute:

`./mvnw spring-boot:run`

To run the SvelteKit codebase, execute:

`npm run dev`

Then navigate to the URL SvelteKit provides on localhost to play the game.

Additionally, make sure a Gemini API key is saved in .env in the phish-patrol-frontend/ directory.
